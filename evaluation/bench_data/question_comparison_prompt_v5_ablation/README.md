# Диагностический эксперимент — черновик v5

Это первая итерация sol до последующих исправлений основного агента.
Не путать `production/` в этом каталоге с итоговым v5: здесь это имя варианта
на момент вызова. Точные отправленные промпты сохранены в protocol.json и
sent_system_prompt/sent_user_message каждой записи.

**Ошибка первоначального эксперимента:** `v5-structured` в этих первых
артефактах оставил универсальный выбор языка вместо явного целевого языка
из-за несовпавшей строковой замены. Его нельзя использовать для чистого
вывода об эффекте локализации. Ошибка исправлена с проверкой наличия якоря
и отдельным тестом; корректный повтор — в `corrected/`: по одному первому
запросу десяти случаев, обе модели, без серии замен. v4 и финальный v5
в нём получены из соответствующих полных артефактов, все промпты сверены
побайтно; исправленный английский вариант вызван заново.

Три первоначальных варианта: v4, новая структура с английскими инструкциями, полная
локализация того же черновика. По 18 ответов на модель и вариант: четыре
серии по три замены и шесть одиночных случаев. Один образец на ситуацию;
этого достаточно для поиска дефектов, но не для уверенного ранжирования.

Исходный v4 — выбранные соответствующие запросы из уже сохранённого прогона
6 сентября, не новые вызовы. Взяты все заданные случаи, sample=1, первые три
шага серий. Совпадение системного и пользовательского промпта с frozen-v4
проверено побайтно для всех 36 запросов; derivation указан в метаданных.

Новые варианты: оба провайдера завершились без ошибок, по 18 ответов.
Английский структурированный вариант оставил у Qwen дословный цикл и
мужской род в украинском случае. Локализованный черновик убрал дословные
повторы в этой маленькой выборке, но сохранил мужской род, домыслы и ошибку
времени планируемого звонка. Gemini на локализованном варианте ближе к цели,
но предложил женщине вопрос о передаче работы/выходном как скрытый совет.

Поэтому основной агент дополнительно уточнил: прежние вопросы ассистента
не источник фактов; род берётся из слов человека; планируемое не является
прошедшим; нельзя предлагать готовые варианты ответа и скрытый совет;
инструкция next направляет к цели молитвы, а не к последней фразе.
После этого проведён отдельный полный прогон итогового кандидата v5.
