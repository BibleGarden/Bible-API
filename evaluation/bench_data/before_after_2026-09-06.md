# Наводящий вопрос: до и после (ClickUp 86cbehxm2, для Марии)

Сначала — как было: боевой промпт **v3**, клиент шлёт на каждое «заменить
вопрос» одно и то же тело, поля `skipped_questions` нет, повторы никто не
проверяет (артефакт `bench_data/questions_qwen30b_v3_series.jsonl`, сэмпл 1).
Затем — как стало: живой локальный эндпоинт 9084 на 2026-09-06, промпт
**v4**, поле `skipped_questions`, фильтр повторов и вторая генерация
(протокол — `bench_data/live_9084_2026-09-06.md`).

Тексты дословные, ничего не отобрано: по одной серии подряд, все шаги.
Строка метрик под каждой серией — факты, без оценки: что вопросы значат,
решает Мария.

**По одному сэмплу на серию — это не замер, а стенограмма.** На одном прогоне
модель может и повториться, и не повториться; усреднённые по шести сэмплам
числа лежат в `evaluation/README.md` («Промпт наводящего вопроса v4»,
«Фильтр повторов на v4»). Здесь показано, как это читается человеком.

Важно про вторую часть каждой серии: она снята с **накапливающим клиентом** — то есть с
тем, каким приложение станет, когда начнёт присылать заменённые вопросы. Для
серии из дневника ниже есть и третья колонка: сегодняшний клиент (одинаковое
тело) на новом промпте — видно, сколько даёт один только промпт.
